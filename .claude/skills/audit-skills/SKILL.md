# audit-skills

Scan the repository for all skills and produce a structured YAML inventory.

## What to do

1. **Find all skills** — this repo is a Claude Code plugin marketplace, so skills live in two places:
   - **Plugin skills** — glob `*/skills/*/SKILL.md` from the repo root (matches `<plugin>/skills/<skill>/SKILL.md` for every plugin sibling folder).
   - **Repo-local skills** — glob `.claude/skills/*/SKILL.md` (skills only used while working *on* this marketplace).

   If neither glob matches anything, report that no skills were found and still write an empty YAML file.

2. **For each skill, extract:**
   - `skill_name` — the skill's folder name (e.g. `audit-skills`)
   - `plugin` — the plugin folder name from the path; for `.claude/skills/<skill>` use `(repo-local)`
   - `description` — the `description` field from the SKILL.md YAML frontmatter
   - `last_updated` — run `git log -1 --format=%as -- <full path to SKILL.md>` to get the ISO date of the last commit that touched the skill file; if the file is untracked use today's date
   - `scope` — look for a `scope` field in the frontmatter; if absent, infer it from the description (e.g. "testing", "documentation", "code-generation", "data", "workflow") — keep it to one short word or hyphenated phrase
   - `project` — look for a `project` field in the frontmatter; if absent, default to `legal_tracker`

3. **Write the YAML file** to `.claude/skills-inventory.yaml`. Use this structure:

```yaml
# Skills inventory — auto-generated by audit-skills
# Last run: <today's date>

skills:
  - skill_name: example-skill
    plugin: example
    description: "Does X"
    last_updated: "2026-01-15"
    scope: code-generation
    project: legal_tracker
```

4. **Report** a brief summary to the user: how many skills were found, the path of the YAML file written, and a table listing the skills grouped by plugin.

## Edge cases

- If a SKILL.md has no `description` in its frontmatter, use the first non-empty line of the file body as a fallback description (truncated to 120 chars).
- If `git log` is unavailable, use today's date for `last_updated`.
- Match exactly the two glob patterns above — do not recurse deeper. A skill is exactly one `SKILL.md` at `<plugin>/skills/<skill>/SKILL.md` or `.claude/skills/<skill>/SKILL.md`.
